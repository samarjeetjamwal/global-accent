# global-accent
**Global Accent Translator** is a unique AI-powered speech transformation tool.  
Speak into your microphone and watch your speech get translated **into the same language but in a completely different global accent**.  

It’s built with:
- **HTML, CSS, and JavaScript** (Frontend)
- **Gemini AI API** (via Google AI Studio)
- **Serverless Function** (Vercel/Cloudflare Workers ready)

---

## 🚀 Features
- 🎤 **Live microphone input**
- 🌎 **Accent transformation** without changing the language
- ⚡ **Real-time AI processing**
- 💻 **Runs entirely in the browser** (frontend) with a serverless backend for AI calls
- 📱 **Responsive design** for mobile and desktop
