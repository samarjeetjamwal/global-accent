Global Accent Translator

Speak → convert to the same language in a different accent → play. Remote LLM (Gemini) or local fallback available.

The proxy is required so you don't expose API keys to clients. It should accept JSON {language, text, target_accent} and return JSON {accent_text, phonetic, speech_tags}.
